# Limitations

This is a stylized computational model. It is useful for comparing mechanisms
inside the specified assumptions, not for forecasting real crises.

Known limitations:

- no strategic manipulation or coalition formation yet;
- no learning dynamics in trust updates;
- social welfare is a proxy metric;
- Prolog rules are institutional constraints, not a full legal/normative theory;
- Lean formalizes only a tiny deterministic core, not the stochastic simulator.

The project should make claims only where code, tests, experiments, or formal
definitions provide evidence.
